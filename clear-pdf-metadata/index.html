What this cleaner does—and does not—clear

“Metadata” can mean several different things. This tool deliberately targets standard document properties and the PDF catalog metadata reference. It is not a redaction or malware-removal tool.

Standard propertiesClearedTitle, author, subject, keywords, creator, producer and standard creation/modification dates.
Metadata streamClearedThe document-level metadata reference is removed when present.
Visible page contentNot changedText, images and page layout remain part of the PDF.
Comments and attachmentsNot clearedAnnotations, form values, embedded files, scripts and other nonstandard content require a deeper PDF audit.

How to clear metadata from a PDF

Choose one or more PDFs, review the properties detected above, and select Clean PDFs. Download the generated copy only after its verification message confirms zero populated common fields and an unchanged page count.

When to use a deeper inspection

Use a dedicated PDF security or forensic tool when a document may contain comments, form data, embedded files, JavaScript, signatures, hidden layers or sensitive visible text. Clearing document properties does not remove those items.

Private, local processing

The selected file, cleaned copy and verification pass stay inside your browser. This site does not require an account or upload the PDF to an application server.

Keep the original file

The cleaner creates a separate download and never overwrites your source PDF. Keep the original until you have opened the cleaned copy and confirmed that it still displays as expected.

Frequently asked questions

How can I clear PDF metadata online?

Choose a PDF, review the detected properties, select Clean PDFs, and download the cleaned copy. Processing happens locally in your browser.

How do I verify that PDF metadata was cleared?

After cleaning, this page reopens the generated copy locally, counts the common metadata fields that remain, and confirms whether the page count is unchanged.

Which PDF metadata fields are cleared?

The tool targets title, author, subject, keywords, creator, producer, creation date, modification date and the document metadata stream reference.

Does clearing metadata remove visible text or annotations?

No. Metadata cleaning is not redaction. It does not remove visible page text, images, comments, attachments, form values or other embedded content.

Are PDF files uploaded for cleaning?

No. Inspection, cleaning and verification run locally in the browser without uploading the selected PDF to this website.
